# Calgary accountant introductions: lead-gen site

A static site (generated by `build.py`) plus one Vercel serverless function (`api/lead.js`) that emails each
form submission to you through Resend. Design rules are in `DESIGN.md`.

```
build.py          all page content and templates; CONFIG block at the top
static/           CSS, form script, favicon, self-hosted fonts (copied into dist/)
api/lead.js       POST /api/lead -> validates, drops honeypot spam, emails the lead
vercel.json       build = python3 build.py, output = dist
```

Local preview: `python3 build.py && cd dist && python3 -m http.server 8000` (the form needs Vercel to post).

## Before launch

1. **Name and domain.** Edit `BRAND`, `WORDMARK` and `DOMAIN` at the top of `build.py`. Optional: `PHONE`,
   `CONTACT_EMAIL`, `HEADSHOT` (put the photo in `static/img/`).
2. **Privacy page.** It's a marked draft. Fill in the retention period and have it checked against Alberta's PIPA.
3. **Compliance.** Confirm with your MGA and the Insurance Council of Alberta how the site describes you and the
   optional insurance-contact consent.
4. **Partner.** Confirm Jonathan's intake criteria. The site names no firm.

## Deploy

1. Create an empty private GitHub repo, then from this folder:
   `git remote add origin git@github.com:<you>/<repo>.git && git push -u origin main`
2. Vercel → Add New → Project → import the repo. Vercel reads `vercel.json`; no framework preset needed.
3. Vercel → Project → Settings → Environment Variables (Production and Preview):
   - `RESEND_API_KEY`: from resend.com
   - `LEAD_TO_EMAIL`: where leads go (comma-separate several)
   - `LEAD_FROM_EMAIL`: a sender on a domain verified in Resend, e.g. `Leads <leads@yourdomain.ca>`
   Redeploy after adding them.
4. Vercel → Settings → Domains → add the domain and set the DNS records it shows. In Resend, verify the same
   domain (SPF/DKIM records) so lead emails don't land in spam.
5. Send one test lead from the live form and confirm the email arrives.
6. Google Ads: set `GADS_ID` and `GADS_LEAD_LABEL` in `build.py`, push, and the thank-you page fires the conversion.
   Submit `/sitemap.xml` in Search Console.

## Search and AI visibility settings (top of build.py)

- `SITE_URL`: leave blank. Vercel's production domain is used for canonicals, sitemap and schema, and switches
  to your custom domain automatically once you add it. Preview deployments get `noindex`.
- `REVIEWER`: fill in Jonathan's name, credentials, firm, URL and a one-line bio. That adds "Tax content reviewed by"
  to every page, a reviewer section on /about/, and `reviewedBy` in the structured data.
- `OPERATOR_LINKS`, `OPERATOR_LICENCE`, `HEADSHOT`: your LinkedIn and licence; they appear on /about/ and in the
  Person schema.
- `LAST_REVIEWED`: bump when you re-check content (a page can override with `reviewed="YYYY-MM-DD"`). Drives the
  visible "Last reviewed" line and sitemap `lastmod`.
- `GSC_VERIFY`, `BING_VERIFY`: verification codes for Google Search Console and Bing Webmaster Tools.
- `INDEXNOW_KEY`: the key file is served at `/<key>.txt` so new URLs can be pinged to Bing via IndexNow.
- Sources: CRA citations per page live in `SRC` / `SOURCES` in build.py.
- Share image: `static/og.png`, rendered from `scripts/og.html`. Regenerate it if the brand name changes.
